# Alontito Knowledge Base

Общая база знаний агентов Алонтито. Каждый агент учится локально
и делится только проверенными замерами уроками.

## Структура
- knowledge/lessons.jsonl — уроки (append-only, одна JSON-запись на строку)
- skills/skills.json — общие навыки
- facts/facts.jsonl — проверенные факты из интернета
- meta/schema.json — формат записей

## Правила синхронизации
1. Только добавление (append-only). Чужие записи не удалять и не изменять.
2. Урок публикуется только с approved=true (подтверждён замером или человеком).
3. Цикл: pull -> слияние своих новых записей -> push.
4. Доступ: fine-grained PAT, только Contents Read/Write на этот репозиторий.
